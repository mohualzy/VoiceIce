## 项目背景

在某些极寒之地，人们说出的话语会瞬间凝结成冰，无法被当场听见。若想聆听，须将冰块带回家中慢慢煮化：用温火，话语便轻柔舒缓；用烈火，话语便急促激烈。

**言冰** 借用这个意象，尝试回应一个现实命题：当今时代，人与人之间的当面沟通愈发艰难，亲子摩擦、情侣争吵屡见不鲜。言冰希望成为一面声音的镜子，让人们在事后冷静地重听一段话，观察语速、音调、响度和情绪张力如何改变沟通感受。

## 核心算法

音频处理和分析逻辑集中在 `utils.py`。

### 温度驱动的音频处理

`process_audio_speed_and_pitch(y, temperature, sr)` 是当前主处理入口：

- **Time Stretch**：温度低于 1.0 时放慢语速，高于 1.0 时压缩语速。
- **Pitch Shift**：使用实际采样率 `sr` 做音高变换，避免把不同采样率文件硬编码为 22050 Hz。
- **低通滤波**：温度低于 1.0 时削弱高频，让声音更柔和。
- **软削峰饱和**：温度高于 1.0 时用 `tanh` 增加谐波张力，同时控制爆音风险。

### 原声诊断

`analyze_emotion_features(y, sr)` 使用 `librosa` 提取真实声学特征：

- RMS 能量：整体响度。
- ZCR 均值：过零率，反映信号变化的尖锐程度。
- MFCC 前 13 维均值：音色特征摘要。

情绪倾向目前采用轻量规则判断：

| 条件 | 判定 |
|------|------|
| RMS > 0.05 且 ZCR > 0.1 | 激烈 |
| RMS < 0.02 | 平静 |
| 其他情况 | 中性 |

### 可视化

- `draw_waveform_plotly`：绘制交互式波形图，并对长音频做降采样展示。
- `draw_spectrogram`：绘制 Matplotlib 声谱图。
- `draw_f0_curve`：使用 `librosa.pyin` 提取基频 F0，并过滤无声段。
- `draw_emotion_timeline`：按 0.5 秒分帧计算 RMS/ZCR，映射为 0 到 1 的激烈度面积图。

## 快速开始

### 环境要求

- Python 3.9+
- 推荐使用虚拟环境（`venv` 或 `conda`）

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动应用

```bash
streamlit run main.py
```

如果当前环境中 `streamlit` 命令不可用，也可以使用：

```bash
python -m streamlit run main.py
```

启动后访问 `http://localhost:8501`。

## 使用指南

1. 在左侧"拾遗冰窖"上传 `.wav` / `.mp3`，或点击麦克风录制现场音频。
2. 通过"掌灯予暖"滑块调节温度：低温更舒缓，高温更紧张。
3. 在"见字如面"中播放原声和处理后音频，对比波形与 F0 音调轨迹。
4. 在"闻声绘影"中查看频域声谱变化。
5. 在"解语手札"中查看原声 RMS、ZCR、MFCC 摘要和情绪判定。
6. 在"情绪温度"中查看 0.5 秒分段激烈度曲线，并定位峰值时刻。
7. 在侧边栏"流年冰迹"中切换历史音频，或批量删除不再需要的记录。

## 当前限制

- `librosa.pyin` 的 F0 提取对 CPU 有明显消耗，较长音频在 Streamlit rerun 时可能需要等待。
- 情绪分析目前是基于 RMS/ZCR 的规则诊断，不是语义理解，也不是机器学习分类器。
- 情绪温度图按 0.5 秒分帧，长音频会生成较多图表数据。
- `local_ice_vault/` 是本地文件夹，不适合作为多人协作或云端存储方案。

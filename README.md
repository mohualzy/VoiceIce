# 🧊 言冰 Voiceice

> *话语凝冰，烹煮听音*
> *Words freeze into ice — cook them to hear what's within.*

---

## 项目背景

在某些极寒之地，人们说出的话语会瞬间凝结成冰，无法被当场听见。若想聆听，须将冰块带回家中慢慢煮化——用温火，话语便轻柔舒缓；用烈火，话语便急促激烈。

**言冰** 借用这个意象，尝试回应一个现实命题：当今时代，人与人之间的当面沟通愈发艰难，亲子摩擦、情侣争吵屡见不鲜，轻则伤情，重则酿成悲剧。言冰希望成为一面声音的镜子——让人们在事后冷静地重听争吵，倾听若换一种语气，结果会否不同。

---

## 功能简介

| 功能 | 说明 |
|------|------|
| 🎙️ 现场采音 | 直接在浏览器内录制音频，无需额外软件 |
| 📂 文件上传 | 支持上传 `.wav` / `.mp3` 格式音频文件 |
| 🔥 温度调节 | 通过"心火炽度"滑块，在 0.5x–2.0x 区间连续调整语速与音调 |
| 🌊 波形对比 | 交互式可视化，并排展示处理前后的音频波形 |
| 🔬 声谱分析 | 频域声谱图，直观呈现音色能量分布的变化 |
| 📝 情感手札 | 基于温度参数的锋芒/静气指标，辅助反思沟通状态 |
| 🗂️ 历史记录 | 自动持久化至本地，会话重启后历史音频仍可恢复 |

## 核心算法

言冰的音频处理由 `utils.py` 中的 DSP 引擎驱动，核心逻辑如下：

### 温和模式（温度 < 1.0）
- **时间拉伸（Time Stretch）**：降低语速，让话语更舒缓
- **音调下移（Pitch Shift）**：音色偏低沉、柔和
- **低通滤波（Butterworth Low-pass Filter）**：削弱刺耳高频，模拟"轻声细语"的听感
- **增益衰减**：整体音量轻微降低，配合柔和氛围

### 激烈模式（温度 > 1.0）
- **时间压缩（Time Stretch）**：语速加快，节奏紧张
- **音调上移（Pitch Shift）**：音色偏高亢、尖锐
- **软削峰饱和（Soft Clipping Saturation）**：利用双曲正切函数 `tanh` 引入谐波失真，模拟"嘶吼感"，同时天然防止爆音

## 目录结构

```
voiceice/
├── main.py              # 主程序入口，状态机与路由逻辑
├── ui_components.py     # Streamlit UI 组件（侧边栏、标签页、控件）
```

## 快速开始

### 环境要求

- Python 3.9+
- 推荐使用虚拟环境（`venv` 或 `conda`）

### 安装依赖

```bash
git clone https://github.com/your-org/voiceice.git
cd voiceice
pip install -r requirements.txt
```

### 启动应用

```bash
streamlit run main.py
```

启动后，浏览器将自动打开 `http://localhost:8501`。

## 使用指南

1. **上传或录制音频**：在左侧"拾遗冰窖"面板上传文件，或点击麦克风按钮进行现场录音。
2. **调节心火炽度**：通过主界面滑块选择温度（0.5 = 极度温和，2.0 = 极度激烈）。
3. **对比聆听**：在"见字如面"标签页中，分别播放原声与处理后的音频，对比波形变化。
4. **查看声谱**：切换至"闻声绘影"标签页，观察频域能量的分布差异。
5. **阅读手札**：在"解语手札"标签页中查看当前温度下的情感指标分析。
6. **管理历史**：侧边栏"流年冰迹"区域展示所有历史音频，支持一键切换或批量删除。
